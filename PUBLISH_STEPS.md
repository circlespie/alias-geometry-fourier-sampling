# Author publication steps

The repository has been pushed to GitHub. The annotated `v1.0` tag preserves
its initial verification snapshot; subsequent metadata updates are on `main`.
Do not move the tag.

1. Post the paper to arXiv with the repository URL in its reproducibility line.
   Optionally attach the `v1.0` repository snapshot as ancillary files.
2. Make the repository public on github.com: Settings → General → Danger Zone → Change visibility.
3. Add the arXiv id to `README.md` and `CITATION.cff`, commit, and push to `main`.
